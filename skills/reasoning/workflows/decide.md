# Workflow: Decide

Make a structured decision, from problem framing through to monitoring.

## Purpose

Decision-making is the process of selecting among options. This workflow provides structure for consequential decisions — decisions where the stakes justify a systematic approach.

## When to Use

- The decision is consequential (high stakes, irreversible, or both)
- Multiple options exist with different trade-offs
- Multiple stakeholders are involved
- Uncertainty is significant
- The decision benefits from structured analysis

## Workflow

### Phase 1: Frame the Decision

**Goal**: Define what decision is being made and why.

1. **What is the decision?** State it precisely.
2. **Why does it matter?** What are the stakes?
3. **Who is the decision-maker?** Who has authority?
4. **What is the deadline?**
5. **Is the decision reversible?**

**Methods**: Problem framing, constraint analysis

### Phase 2: Identify Options

**Goal**: Generate a comprehensive set of options.

1. **List obvious options**
2. **Generate creative options** (what else could you do?)
3. **Include "do nothing" as an option** (it's often viable)
4. **Include hybrid options** (combining elements of others)
5. **Check for missing options** (what would a competitor do?)

**Methods**: Divergent thinking, alternative generation

### Phase 3: Define Criteria

**Goal**: Establish what makes one option better than another.

1. **What matters?** List all relevant criteria
2. **Weight the criteria**: What's most important?
3. **Check for independence**: Are criteria overlapping?
4. **Validate**: Do the weights reflect actual values?

**Methods**: Multi-criteria decision, value elicitation

### Phase 4: Evaluate Options

**Goal**: Assess each option against each criterion.

1. **Score each option on each criterion**
2. **Use evidence where available**, judgment where not
3. **Note uncertainty in scores**
4. **Identify dominated options** (worse on all criteria)

**Methods**: Multi-criteria decision, evidence evaluation

### Phase 5: Analyze Trade-Offs

**Goal**: Understand what you're giving up with each option.

1. **What are the key trade-offs?**
2. **Which criteria conflict?**
3. **What would make you switch from one option to another?**
4. **Is any option clearly superior?**

**Methods**: Trade-off analysis, sensitivity analysis

### Phase 6: Assess Risks

**Goal**: Identify what could go wrong with each option.

1. **What are the risks of each option?**
2. **What's the worst case?**
3. **What are the second-order effects?**
4. **What are the risks of NOT choosing each option?**

**Methods**: Risk analysis, premortem, second-order thinking

### Phase 7: Decide

**Goal**: Select the best option.

1. **Review the analysis**: Does one option clearly dominate?
2. **Check intuition**: Does the analytical result feel right? If not, why not?
3. **Make the decision**: Select the option with the best overall balance
4. **Document the rationale**: Why this option over the others?

**Methods**: Decision methods, convergence

### Phase 8: Verify and Monitor

**Goal**: Ensure the decision is implemented and track outcomes.

1. **Define success criteria**: How will you know if it was a good decision?
2. **Identify early warning signs**: What would suggest the decision was wrong?
3. **Set review points**: When will you revisit the decision?
4. **Monitor outcomes**: Track against success criteria

**Methods**: Verification, monitoring, calibration

## Common Failure Modes

- **Narrow framing**: Not considering enough options
- **Confirmation bias in evaluation**: Scoring options to favor the preferred one
- **Analysis paralysis**: Never reaching the decision phase
- **Decision without monitoring**: Deciding but not tracking whether it worked
- **Ignoring reversibility**: Treating reversible decisions as irreversible (or vice versa)
- **Post-decision rationalization**: Defending the decision instead of evaluating it
