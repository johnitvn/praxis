# Meta-Reasoning

Reasoning about reasoning.

## Purpose

The meta layer monitors, evaluates, and regulates the agent's own reasoning processes. It is the "executive function" of the Praxis skill.

## Core Questions

Meta-reasoning asks:

1. **Am I thinking about this the right way?**
2. **What assumptions am I making?**
3. **How confident should I be?**
4. **What would make my conclusion wrong?**
5. **Should I continue, change approach, or stop?**

## The Meta Loop

Every reasoning process should periodically check:

```
Apply reasoning method
    │
    ▼
Meta-check:
├─ Assumptions still valid?
├─ Biases detected?
├─ Confidence calibrated?
├─ Alternatives considered?
├─ Verification passed?
├─ Should I continue?
    │
    ▼
Adjust or continue
```

## When to Invoke Meta-Reasoning

Meta-reasoning is not always-on. It is invoked at specific points:

| Trigger | Meta-Check |
|---------|-----------|
| Before starting | Is this the right approach? |
| After forming a hypothesis | Am I anchoring? |
| After reaching a conclusion | Could I be wrong? |
| When confidence is high | Am I overconfident? |
| When confidence is low | Is the uncertainty reducible? |
| When stuck | Am I in a mental rut? |
| Before deciding | Have I considered alternatives? |
| After deciding | What would make me change my mind? |
| When stakes are high | Am I being thorough enough? |
| When time is short | Am I cutting corners? |

## The Most Important Question

> **"What would make my current reasoning wrong?"**

If you cannot answer this question, you don't understand your own reasoning well enough.
