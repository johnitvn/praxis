# Consistency Check

Verify that reasoning is internally consistent — no contradictions, no double-counting, no incompatible assumptions.

## Purpose

Internal consistency is a minimum standard for valid reasoning. An inconsistent argument cannot be entirely correct.

## Consistency Dimensions

### 1. Logical Consistency

Do the conclusions follow from the premises without contradiction?

**Check**:
- If A implies B, and I believe A, do I also believe B?
- Do I hold any beliefs that are logical contraries? (A and not-A)
- Do my conclusions contradict each other?

### 2. Assumption Consistency

Are assumptions compatible with each other?

**Check**:
- If assumption X and assumption Y are both true, is that possible?
- Do any assumptions contradict each other?
- Do later assumptions contradict earlier ones?

### 3. Method Consistency

Are the methods used compatible?

**Check**:
- Do the methods share compatible assumptions?
- Does method B's input require something method A's output can't provide?
- Are methods being used in ways that contradict each other's assumptions?

### 4. Evidence Consistency

Does all the evidence point in the same direction?

**Check**:
- Is there evidence that contradicts the conclusion?
- Is evidence being weighted differently in different parts of the reasoning?
- Are there double standards for evidence?

### 5. Valuation Consistency

Are values and criteria applied consistently?

**Check**:
- Would I make the same trade-off in a different context?
- Are criteria weighted consistently across options?
- Would I reverse the decision if the options were swapped?

## Procedure

### Step 1: Pairwise Check

Check each pair of key claims for consistency:
- Can both be true simultaneously?
- If one is true, does it constrain the other?

### Step 2: Transitive Check

Check chains of reasoning:
- If A → B → C → D, is D actually consistent with A?
- Are there any circular dependencies?

### Step 3: Counterfactual Check

If the conclusion were different:
- Would any part of the reasoning change?
- Would you still hold the same premises?
- Would you weight evidence differently?

### Step 4: Symmetry Check

Would you make the same judgment if:
- The options were labeled differently?
- The stakeholders were different?
- The context was slightly different?
- The outcome was framed as a loss instead of a gain?

## Common Consistency Failures

| Failure | Example |
|---------|---------|
| **Double standard** | Requiring more evidence for alternatives than for the preferred option |
| **Moving goalposts** | Changing criteria when the preferred option fails |
| **Special pleading** | Making exceptions for the preferred option without justification |
| **Circular reasoning** | Using the conclusion as a premise |
| **Contradictory assumptions** | Assuming both "the market is efficient" and "we can beat the market" |
| **Inconsistent weighting** | Weighting a criterion heavily in one comparison but ignoring it in another |

## When to Use

- After reaching a conclusion, before finalizing
- When multiple methods produce different results
- When reasoning is complex with many steps
- When stakes are high and consistency errors would be costly
